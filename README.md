# 🧠 Brain Boost Game

Brain Boost is an offline-first Android brain training game. Sharpen your mind with fun challenges, earn coins, complete daily tasks and spin the lucky wheel.

## Features
- Multiple levels with increasing difficulty
- Coins and rewards system
- Daily tasks
- Lucky spin
- Works offline
